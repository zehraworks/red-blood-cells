# 🩸 Red Blood Cells

**Interactive 3D Red Blood Cell Simulation using Three.js**  
A lightweight, real-time visualization of red blood cells in motion — complete with hover effects and smooth, dynamic behavior.

## 🎯 Features

- 🧬 Realistic 3D red blood cell models
- 🖱️ Mouse hover interactions with visual feedback
- 🌊 Smooth animations simulating blood flow
- 💻 Built with [Three.js](https://threejs.org/) for WebGL rendering
